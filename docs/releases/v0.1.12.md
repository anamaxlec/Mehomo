# Mehomo v0.1.12

本次完善日程管理，加入应用版本与 GitHub 更新检测，并补上首页进入登录页的动效。

## 日程与执行记录

- 修复新建与编辑日程时的闪退，表单适配窄屏与大字号。
- 重复规则支持每隔几分钟、每小时、每天、每周、每月、每年与高级 Cron。编辑时自动回填已有规则和时间；高级模式支持五段、六段表达式、范围、步长、星期与月份名称、`@daily` 和 `@every` 等规则。
- 日程卡片显示规则说明、执行次数、目标会话和下次执行预览，可按名称或启用状态排序。时间预览遵循 Bot 时区，并处理夏令时跳过与重复时刻。
- 新建任务可选择 Agent、模型、思考强度、工作目录，或指定已有会话；会话选择支持完整的分页列表。
- 执行记录支持分页、刷新，展示执行状态、开始与结束时间，展开和复制结果或错误，并打开对应执行会话。
- 日程规则和星期选择采用可换行的 M3E 选项，选中项显示主题色底与勾选图标。

## 版本与更新

- “我的”新增“版本与更新”，显示当前安装版本，页尾也显示版本号。
- 打开应用时自动检测 GitHub 最新正式发行版，每天检查一次；支持手动检查与自动检查开关。
- 发现新版本时，在应用内展示版本号、更新日志、APK 大小与正式版下载入口。
- “稍后”可关闭本次版本的自动提醒，也可从“版本与更新”再次查看更新详情。

## 登录动效

- 首页进入 Memoh Cloud 和自托管登录时，采用统一的水平位移与短渐隐。
- 登录页面的返回按钮与系统返回会回到服务器选择页，页面按相反方向过渡。

安装包：`Mehomo-v0.1.12-release.apk`，支持 Android 8.0 及以上。
