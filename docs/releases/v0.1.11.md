# Mehomo v0.1.11

本次优化会话与管理页面的返回动效。

- 工具栏与系统按键返回采用 Flare 风格的水平位移与短渐隐，让普通返回更利落。
- 左右边缘的预测性返回按手势进度连续调整位移、缩放和透明度，拖动时保留当前页面的预览。
- 统一手势拖动、松手收尾与取消回位的渐隐曲线，取消手势后立即返回也能顺畅衔接。

下载 `Mehomo-v0.1.11-release.apk` 安装，支持 Android 8.0 及以上。正式包沿用此前发行版签名，可直接覆盖升级。

本版通过 214 项 JVM 测试、release 构建与 lint，以及 17 项 API 36 导航回归，包含返回动效、浮动底栏、切换方向和字号适配；另已录制检查会话与 Bot 设置页的普通返回、左右边缘手势和取消回位。
