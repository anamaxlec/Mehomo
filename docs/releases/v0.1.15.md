# Mehomo v0.1.15

- 修复重进会话时运行状态丢失、后台恢复闪动和返回首页出现刷新提示的问题；上下文用量自动更新，清空历史后不再残留旧任务。
- 优化超长思考和工具详情的展开性能，保留阅读位置，放慢过程动画，并移除重复的“正在处理”提示。
- 完善运行中的排队与插话操作，提交失败保留草稿；长草稿在收起键盘后继续完整显示。
- 新增 Bot 推荐问题、分类使用示例和应用“试一试”，支持提示词预填、草稿替换确认及会话多选删除。
- 日程支持查看每次运行的会话和更早记录；补充工作空间暂停状态、实际资源额度及连接器工具加载失败原因。
- 打磨 M3 Expressive 的标题、按钮、日程卡片和示例弹层，改善大字体下的输入布局，并修复搜索跨页残留及返回行为。
