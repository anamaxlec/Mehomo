# Mehomo v0.1.14

- 新增 Bot 推荐问题、分类使用示例与提示词预填，支持换一组和草稿替换确认。
- 可用应用增加“试一试”，快速开始演示对话。
- 会话支持多选和批量删除，保留未删除的选项供重试。
- 日程可展开查看每次运行的会话并加载更早记录，执行会话归到对应日程中。
- 补充运行环境暂停状态、实际资源额度和连接器工具加载失败原因。
- 修复会话重进时运行状态丢失、后台恢复闪动、上下文用量不自动更新，以及清空历史后旧任务残留。
- 优化超长思考和工具详情的展开性能，保留阅读位置，并放慢过程动画。
- 运行中输入默认加入后续队列，支持插话、转换和移除；提交失败保留草稿。
- 移除输入区重复的“正在处理”提示，保留工具与思考动画。
