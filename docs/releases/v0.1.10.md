# Mehomo v0.1.10

本次更新补齐 Memoh Cloud 的原生管理功能，完善附件、日程、内容阅读与离线历史，并统一浮动导航和返回动效。新增页面沿用 Material 3 Expressive 的分组列表、图标配色、按钮、表单和菜单。

## 原生管理与 Cloud 团队

- **Bot 管理与设置：** 创建和管理 Bot，调整资料、默认模型、上下文压缩、工具审批及渠道行为。
- **Agent 设置：** 配置认证与运行选项，安装依赖，启停 Agent 并设置默认项。
- **模型与工具服务：** 配置模型供应商、查看模型目录与能力、测试连接；管理记忆、搜索、网页读取、语音合成、转录和视频服务。
- **连接与自动化：** 接入连接器 OAuth/API key、消息渠道与路由、Computers、事件 Hooks；MCP 支持 HTTP/SSE/stdio、启停、连接探测、完整工具列表、配置导入导出与 OAuth 授权。
- **工作空间与权限：** 管理运行状态、资源额度、快照与恢复，配置 Bot 成员、渠道管理者和访问规则。
- **备份与恢复：** 导出 Bot 备份包，导入前查看内容，逐项选择合并、覆盖或跳过。
- **Cloud 团队与个人资料：** 切换团队，管理团队资料、成员、邀请和所有权，查看套餐额度并进入官方账单流程；编辑个人资料与渠道身份。

以上入口位于“我的”，并按 Bot 与工作空间、模型与服务、连接与自动化、账号分组。

## 附件、内容阅读与离线历史

- 文字和附件草稿按账号、团队、Bot、会话保存，重新进入会话可继续编辑。
- 支持拍照、Android 系统分享、原图或压缩发送；附件统一在展开的输入框内预览、移除和管理。
- 新增数学公式、Mermaid 和静态 SVG 显示，渲染资源随安装包提供。
- PDF 支持原生分页预览，Markdown、文本及支持的 Office 文档可在应用内阅读、保存或用系统应用打开。
- 可选择保存最近 10/30/50 个会话，在“离线历史”中浏览、搜索和清理。

## 日程与记忆

- 日程支持每天、每周和自定义 cron，可选择时区并预览执行时间。
- 任务可配置 Agent、模型、思考强度、执行位置和运行限制，支持启停及执行记录查看。
- 完善记忆关系浏览和记忆管理入口。

## M3E 导航与界面打磨

- 浮动底栏覆盖主页面、Bot 功能、管理菜单、离线历史和工作空间，Bot、模型及团队设置中可直接切换页面。
- 底栏共用选中状态与自定义顺序，滚动时收缩，键盘出现时收起；页面根据底栏实际高度预留空间，放大字号后仍可完整操作最后一项。
- 页面切换方向跟随底栏的实际排列，覆盖相邻切换、跨页点击、自定义排序和 RTL 布局。
- 返回动效参照 Flare 调整位移、短渐隐与预测性返回，左右边缘手势均跟随进度；修复快速进入后返回、取消手势后返回时的闪动。
- 修复会话进入时内容跳动；首屏使用骨架屏，分页使用 48dp 加载球，两种加载提示依次出现。
- 修复 Bot 刷新时将已取消的请求显示为失败的问题，完善断网后的会话恢复。
- 调整“我的”页面分组间距，为新入口补齐主题配色中的不同图标色调。

## 安装与验证

下载 `Mehomo-v0.1.10-release.apk` 安装，支持 Android 8.0 及以上。正式包沿用此前发行版签名，可直接覆盖升级。

本版通过 214 项 JVM 测试、release 构建与 lint，以及 15 项 API 36 导航和加载设备测试；设备回归包含浮动底栏、切换方向、预测性返回、字号放大和会话加载。
