# Memoh 上游适配记录 · 2026-11-18

官方正式版仍为 [v1.0.2](https://github.com/felinics/Memoh/releases/tag/v1.0.2)。本轮从上次适配的 `6fa60ca481` 对照到 `main` 的 `fff461e5ad`，共 37 条提交。[上游提交差异](https://github.com/felinics/Memoh/compare/6fa60ca4810f8b1535d6da1489bdeb1302a41cef...fff461e5ad6cb8399d2fc7e9ca7367ec4d08cb06)

| 上游变更 | Android 适配 |
| --- | --- |
| [批量查询 Bot 渠道](https://github.com/felinics/Memoh/pull/1803) | 渠道页用 `GET /bots/{bot}/channels` 读取已配置渠道。旧服务端返回通用 404 时尝试原有逐项接口，权限错误、明确的 Bot 不存在错误和服务端错误会显示在页面上。 |
| [飞书流式回复开关](https://github.com/felinics/Memoh/pull/1777) | 服务端声明 `enableStreaming` 后，飞书配置显示「流式回复」。旧配置缺少该值时默认开启，保存时发送布尔值并保留原凭据和路由。已配置渠道若缺少凭据对象，页面提示刷新并关闭编辑入口。 |
| [聊天报错卡片](https://github.com/felinics/Memoh/pull/1807) | 连接、运行及历史消息提供诊断标识时，卡片支持展开和复制。具有 Bot 管理权限时可从模型服务商认证、权限、余额或请求拒绝类错误跳到模型服务设置。诊断 ID 按同一次请求取值。原位编辑报错显示在该条消息下，保留重试入口。 |
| [会话快照等待上限](https://github.com/felinics/Memoh/pull/1767) | WebSocket 已连接但 8 秒内未收到会话快照时，显示「重新同步」。已加载的历史继续可读，重新订阅期间发送仍要求有效快照。 |
| [Agent 依赖与模型表单修复](https://github.com/felinics/Memoh/pull/1804) | 直连 Agent 登录收到 `agent_dependency_missing` 时，检查该 Agent 声明的依赖并复用安装确认。模型配置已有显式清空数字字段的处理。 |
| [启用状态排序](https://github.com/felinics/Memoh/pull/1814) | Bot 渠道、搜索与抓取服务商及 MCP 列表把已启用项排在前面，组内沿用原有顺序。 |

Android 的工作区文件和对话附件已有原生 PDF 及 DOCX 文本预览，DOCX 的版式渲染仍由 Web 端提供。上游工作区文件轮询优化针对 Web 的持续轮询，Android 的文件页按打开、刷新和写入等操作读取。`return_to` 属于 Web/Desktop 的登录路由，Android 会话通知沿用已支持的登录后打开目标会话。[文档预览](https://github.com/felinics/Memoh/pull/1776) · [文件轮询](https://github.com/felinics/Memoh/pull/1788) · [登录回跳](https://github.com/felinics/Memoh/pull/1802)
