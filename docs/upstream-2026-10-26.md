## Android 接入流程

接入按「选择服务商 → 填写 API key 或账号授权 → 获取模型 → 勾选并保存」组织。复用项目的 Material 3 Expressive 主题、原生 Dialog、分段列表、按钮形变和 motionScheme，按需展开连接参数与高级配置。

- 服务商入口包含官方 187 项公开元数据，按订阅服务和其他 LLM 服务商分组，支持本地搜索。三项订阅中，ChatGPT / Codex、GitHub Copilot 使用账号授权，OpenCode Go 使用 API key；本地服务不强制 API key。
- 已知服务商默认只展示名称及必要凭据，协议、地址和目录来源收进「连接设置」；自定义连接和需要补全账号的地址仍直接展示相关字段。展开设置使用主题动效，继续按钮使用前进图标。
- 普通 API 服务先验证连接；订阅服务授权完成后继续获取模型。失败时保留已创建的服务商，重试不重复创建，错误和恢复入口留在当前弹窗。
- 获取的模型保持服务端的初始启用状态，新导入模型由服务端默认禁用。用户勾选后统一保存，取消不写入勾选；少量模型直接选择，多于六个才显示搜索框。
- 服务商首页以入口和启用数量为主，完整模型表默认收起。编辑单个模型的高级推理和其他高级配置按需展开；隐藏字段不会因为普通编辑而丢失。
- 加载使用固定位置的波浪进度条，并采用当前 Material 3 组件的默认高度。内容尺寸随主题动效变化；连接失败时展示具体可操作的原因，不在弹窗后重复展示同一错误。

服务商列表使用上游公开元数据；目录内容和模型声明由服务端管理。客户端不会依据名称或地址猜测 models.dev 来源，也不会把本地转换结果上传为目录数据。

## 数据与行为适配

| 上游变化 | Android 行为 |
| --- | --- |
| `config.schema_version = 2` | 原生编辑输入 / 输出模态、工具调用、结构化输出、推理开关 / 强度 / 协议 / 预算和默认值。模型编辑、启用开关和批量勾选保存均去掉旧版影子字段，避免旧字段覆盖新配置。保留未编辑的高级字段、未知模态和隐藏的默认推理预算；显式编辑高级配置时尊重删除。 |
| v1 / v2 兼容视图 | 根据服务端返回的模型配置选择写入格式。旧服务端继续使用原编辑和 v1 写入，不把空目录当作 v2 已支持的证据。 |
| `reasoning.default_off` | 缺少有效个人选择时采用服务端的默认关闭状态；没有强度或开关的始终推理模型不被强加控制选项。 |
| `catalog_available = false` | 会话模型选择排除此模型；管理界面仍可识别其不可用状态。 |
| `GET /providers/catalog/models`、`POST /providers/{id}/import-catalog-models` | 支持目录预览和导入、缓存过期提示。已知来源使用服务端目录；失败、空结果或 404 都不会自动切换到接口发现。接口发现保留为用户明确选择的独立动作。平台管理的服务商禁用公共导入。 |
| 自动上下文压缩及日志 | 新服务端移除旧压缩开关、阈值、目标比例和模型编辑，提供只读记录及摘要；每页 20 条，前台每 15 秒静默更新，手动刷新才显示进度。长摘要分块懒加载。旧服务端保留原有配置入口；Discuss probe 模型仍可设置。 |
| 删除 Bot 需输入 URL 名称 | 输入 `bot.name` 后才可确认，严格匹配大小写与空格，不使用显示名称或整条 URL。 |
| 模型服务商额度耗尽 HTTP 402 | 显示额度不足的中文原因，不因此刷新登录凭据或退出账号。 |
| 外部 Agent 旧工具结果 | 兼容 `output`、原始字符串、MCP 文本数组及外层 `content`，结构化字段为空时仍显示实际输出。 |

## 由服务端提供的变化

本轮其余变化涉及按实际预算压缩、单一活动摘要、run 内续跑、原始工具结果分页读取、追加式请求、工具结果产生时截断、retry / edit / Discuss 的压缩接入、Computer 切换提示、减少 spawn_agent 的模型列表、请求摘要复用缓存、取消历史与压缩候选的 24 小时截断，以及清理失败回复前保留重试边界。这些由连接的服务端实施；Android 沿用会话历史分页和既有运行态恢复。

网页端终端 / 浏览器关闭全部 tab 后重置编号的修复不适用于 Android 当前的单工作区界面。

本次仅修改 Android 项目，没有部署服务端。新目录与日志接口需要服务端包含相应提交。模拟器使用本地隔离测试服务，不读取真实账号；真实订阅授权、模型生成、生产服务部署及 Samsung S24+ 实机行为未验证。

正式版为 `0.1.20 (44)`，包括上述适配及消息渠道布局、图标与开关修正，详见[发布说明](releases/v0.1.20.md)。本地验证记录存放在 `outputs/upstream-adaptation-20261026/`、`outputs/channel-layout-20261026/` 和 `outputs/releases/v0.1.20/verification/`。
